# AirMate

AirMate is a native macOS 26+ companion app for monitoring nearby Apple and Bluetooth devices. The project is being built as an original, clean-room implementation with Swift, SwiftUI, AppKit, CoreBluetooth, and IOKit where appropriate.

## Current milestone

- Menu-bar app shell
- Device model and store
- Bluetooth discovery foundation
- Mac battery monitoring
- Device HUD
- Settings

## Requirements

- macOS 26+
- Apple Silicon first
- Xcode 27+

Bundle ID: `com.almosawi.airmate`
